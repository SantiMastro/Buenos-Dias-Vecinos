# FUENTE 6x8 DE BUENOS DIAS, VECINO
#
# Una fuente de bitmap no es arte, es datos: una mascara de bits por glifo. Por
# eso vive como texto y no dentro de un .cs — se edita con cualquier editor, sin
# recompilar, y un glifo torcido se arregla mirandolo.
#
# FORMATO
#   '@' seguido del caracter abre un glifo. El espacio se escribe '@SPC'.
#   Despues vienen OCHO filas de SEIS caracteres: '#' es tinta, '.' es nada.
#   Las lineas que empiezan con '#' en la primera columna y no son parte de un
#   glifo son comentarios; por eso todo comentario arranca en la columna 0 y
#   toda fila de glifo esta indentada dos espacios.
#
# LA CAJA, Y POR QUE ES ASI
#   fila 0-1   acento. Se reserva DESDE EL PRINCIPIO: meter las tildes despues
#              obliga a rebajar la altura de las mayusculas y a redibujar las 26.
#   fila 2     SEPARACION, y no sobra. Sin ella el acento toca la mayuscula y la
#              A con tilde se lee como una A con un pincho encima. Se descubrio
#              mirandola en pantalla, no dibujandola.
#   fila 3-7   mayuscula, cinco de alto. La linea base es la fila 7, la ultima.
#   col 0-4    tinta.
#   col 5      separacion. Es monoespaciada, asi que el hueco entre letras es
#              parte del glifo y no una cuenta aparte.
#
# LO QUE SE PAGO POR LA FILA DE SEPARACION
#   No queda fila bajo la linea base, asi que la coma apoya en ella en vez de
#   colgar. En espanol la enye vale mas que la cola de una coma: sin la fila 2,
#   la tilde de la enye queda pegada y no se distingue de una raya.
